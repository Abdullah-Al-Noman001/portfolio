Put your CV PDF in this folder, for example:

    assets/cv/Abdullah_Al_Noman_CV.pdf

Then open js/data.js and set:

    about: {
      ...
      cvUrl: "assets/cv/Abdullah_Al_Noman_CV.pdf",
    }

The "Download CV" button on the About section will start working.

(This note file can be deleted once your real CV is here.)
